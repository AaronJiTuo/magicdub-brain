# 移除下载专用代理，TikHub 返回链接后直接使用当前网络下载

## 决定与实现

用户明确要求将节点代理逻辑全部移除，网络出口由用户在程序外准备；接受当前尚未完成真实下载验收。该简化是产品边界，不是对特定住宅节点可用性的验收结论。

代码工程本地 0.3.0 候选已移除 MAGICDUB_MEDIA_PROXY 配置、保存和校验、doctor 专用代理状态、独立 Requests 会话及代理分流分支。下载函数直接使用普通 requests.get，沿用运行环境现有网络；同时清除 setup 节点配置交互、下载 skill 的节点询问、README 配置示例及相关代理文档。移除 requests 的 socks 扩展和锁定的 PySocks，已在本地开发环境同步依赖；未修改用户系统或浏览器网络。

保留 V2 接口解析、独立原始音视频规格选择、受控重定向、分段续传、有限重试、失败费用及 asset.json 原地交接。连接错误仅提示检查当前网络并保留结果。未改为 iiilab／yt-dlp，也未因理论上可行而标记真实下载成功。

## 验证与交付边界

95 项测试全部通过；新增普通 Requests 传输测试确认 API、媒体及重定向沿用既有运行环境网络，API Key 不带入媒体请求；音频连接失败保留完整视频，恢复时不重复下载视频或付费解析。Ruff、相关两个 skill 结构检查通过。凭据只保留四种 API Key，doctor 不再提供下载专用代理状态；本机凭据文件未残留旧代理字段。

候选 release.json 已重新生成并校验 37 个文件哈希，版本仍为本地候选 0.3.0。本轮无真实付费 API 请求，费用 ¥0.000000。未提交、推送、发布或切换日常稳定安装，既有 SRT、Alpha、音频质量和费用表改动保留。

## 当前状态

真实 TikHub 整段下载继续标为未验收；后续使用用户自行准备、满足供应商要求的当前网络验证，不恢复程序内节点配置与代理管理。此前临时代理及 iiilab 成功下载的记录保留为历史证据。
