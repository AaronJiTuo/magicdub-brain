# 确认凭据文件优先于环境变量

## 结果

用户确认：`~/.magicdub/cli/credentials` 中有的 key 一律用文件值；仅当文件缺该 key（或为空）时才读环境变量。

## 背景与理由

本机常长期 export 开发用 `FAL_KEY`；若 env 覆盖文件，cli 专用 Key 无法生效。

## 证据与成果位置

- 代码：`load_credentials` 改为文件优先、缺 key 补 env
- 规范：`Releases/06` §2.1／§7.1；README 同步

## 对当前项目的影响

文件与 env 同名时，cli 使用文件中的专用凭据。
