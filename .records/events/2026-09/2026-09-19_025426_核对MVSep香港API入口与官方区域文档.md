# MVSep 香港 API 地址来自官方区域文档，当前代码无需修正

## 结果与依据

用户在账号 API 页面看到统一入口，要求核查代码中的香港地址。已通过用户打开的 `user-api` 页面进入官方完整 API 文档，并与公开文档交叉核对：快速页面示例为 `https://mvsep.com/api/separation/create`；完整文档「区域」明确列出香港基础地址 `https://hk.mvsep.com/api`。代码中的完整地址由这个基础地址加创建路由 `/separation/create` 组成，并非快速页面单独列出的完整示例。

完整文档说明各区域共用账号、API Key 与任务 hash；统一入口按来源地路由，并建议 API 集成显式固定区域入口，以保持任务生命周期一致。处理与存储位于创建任务的区域，下载链接指向任务所在区域。

## 当前代码与影响

核对关联代码仓库本地提交 `062e7ced7be237b257cafaa8e4aea35bfec94877`：`src/magicdub/models.py` 冻结香港基础地址；`src/magicdub/mvsep.py` 的创建、轮询、历史核对及下载主机均保持香港区域，与官方规则一致。此前 60 秒实测也使用该区域并成功，见既有 RESULTS；本轮没有重新提交分离任务。

结论为地址正确，不修改运行代码。本轮只补充来源记录，没有调用收费 API、读取或保存凭据，没有提交或推送 Git 变更。该结论不意味着香港节点对所有用户均为最佳区域。
