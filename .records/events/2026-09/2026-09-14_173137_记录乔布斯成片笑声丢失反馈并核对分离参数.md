# 乔布斯成片笑声丢失反馈与分离参数核对

用户试听乔布斯演讲后反馈部分观众笑声消失，怀疑被分入人声后从背景中扣除。本轮只核对参数与执行逻辑，没有对照片段试听，具体成片与缺失时间点未确定，根因尚未验证。

已核对代码和本机 `jobs1080_20260914_1719` 项目的分离请求：接口 `fal-ai/demucs`，`model=htdemucs_ft`、`stems=[vocals]`、`shifts=1`、`overlap=0.25`、`output_format=wav`，未传 `segment_length` 或选择演讲者／保留笑声的参数；既有两份 Steve Jobs 90 秒验收项目的模型参数相同。

本机 jobs1080 项目记录固定 v0.2.0 / fa7f23b，其背景相减系数为 0.98；正式 v0.4.1 与新版 90 秒验收项目为 1.00。背景按原音减人声重建，再混入译文配音，未单独识别并恢复观众笑声。若笑声被模型放入 vocals，则会随其从背景扣除；这是机制上的可能解释，不能据此认定具体缺失片段的根因，也不能把升级或增大推理参数视为已验证修复。

本轮未改动代码、配置、项目媒体或模型参数，无模型请求、费用或 Git 写操作。后续如开展修复，应先定位用户所指成片和时间点，对比原音、vocals、background 与最终混音；同时保全原稿，检查讲话与笑声重叠场景。
