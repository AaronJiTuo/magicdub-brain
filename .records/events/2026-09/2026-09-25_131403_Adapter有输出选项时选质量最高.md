# Adapter 有输出选项时选质量最高

## 结论

修正 §3.3 第 8 条中「API 用供应商默认格式」：若 API **提供输出格式选项**，选**质量最高**（通常 wav > mp3）。无选项则接受唯一／默认格式。Slot 仍只原样 commit、不后处理。

## 代码

`fal/demucs` 恢复 `output_format: "wav"`。IndexTTS2 等无格式参数的接口不变。
