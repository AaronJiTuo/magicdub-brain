# 取消 Cloud 并收敛为自用 magicdub-skills

## 结果

- 用户明确决定取消 `magicdub-cloud` 项目，整体 MagicDub 规划收敛。
- 原 `magicdub` 暂时保留，当前不推进；优先完成 `magicdub-skills`，skills 主要自用。
- 未来确有 Web 版对外供用户使用的需要时，再决定重启 `magicdub` 仓库或新建仓库。当前不预设仓库、架构和排期，不为未来 Web 预建平台。

## 依据与影响

依据为 2026-09-13 当前对话中用户直接确认的项目决定。这是新的路线取舍，不是对旧事件事实的纠错。它替代此前正式文档中 Web / Cloud 与 skills 并存、“不废弃其他路线”的安排。

已同步项目总览、skills 正式规划、README、AGENTS 项目约束、Release 索引与 CURRENT；三个旧 Web 技术文档标为停止推进的历史参考，正文保留。仅使用当前决定、现有 Release / CURRENT 与上一条短视频范围记录，无新增 Draft 吸收、归档或遗留灵感；已有 Draft 和历史 Record 原样保留。

本次收敛不撤销首版 Codex、三个 skill 入口、短视频优先、多人声音克隆、背景保留、强制对齐、费用统计、配置与视频项目分离或 MIT 选择。公开技能集与对外 Web 服务分别按未来实际需要决定。

## 未完成与下一步

集中把 skills 做到自用可用，按正式规划推进实现与真实媒体验收。本次仅完成 brain 规划同步，未审计或修改关联代码仓库，未删除本地目录、远端仓库或云资源，未执行 Git 提交、推送或公开发布；不代表安装、译制或升级实现已通过验收。
