# Fun-ASR 接入参数与真实验收边界

## 结果

- 源码与当前日常安装均为 v0.5.1 / 86cba45d7bc07520a0571adf90ef8fe5927b8de8；日常入口已指向该安装。fun_asr.py、models.py、audio_quality.py、transport.py 内容一致。此前 CURRENT 中日常仍为 v0.5.0 的描述已过时；本轮未执行升级。
- Fun-ASR 已实现提交、轮询、结果下载、句级时间与 speaker_id 解析，并接入后续翻译配音流水线。模型 fun-asr，diarization_enabled=true，language_hints 按源语言传 [en] 或 [zh]；不显式传 channel_id、speaker_count、special_word_filter 或热词。
- 本机 DASHSCOPE_API_KEY 与 FAL_KEY 均已配置，当前地址为 https://dashscope.aliyuncs.com/api/v1；默认 ASR 仍为 whisper。凭据存在不代表鉴权或模型权限有效。
- HTTPS 使用 DashScope SDK；百炼 oss:// 使用 REST 资源解析请求头。默认上传仍用 fal CDN。新项目 ASR 输入为分离人声的 16 kHz 单声道 PCM16 WAV。
- 现有 test_fun_asr.py 两项测试通过，只验证拒绝响应恢复与缓存成功结果解析，未覆盖真实识别成功。既有验收文档记录 Model.AccessDenied / HTTP 403，本轮未发识别请求，不能断言权限至今仍不足，也不能声称已可用。
- 当前官方 SDK 文档支持单一 language_hints、单声道说话人分离及当前结果结构；官方地址示例使用 Workspace ID 地域地址。旧兼容地址在当前账号上的实时可用性尚未验证，不据此断言必须改地址。

用户报告 fal Whisper 无正常结果，本轮未独立诊断。没有修改代码、凭据、默认模型或既有媒体项目，没有新增付费识别。实际替代前仍需以当前账号完成短音频识别，核验非空文本、时间戳和说话人字段；不要把本地测试当成云端验收。
