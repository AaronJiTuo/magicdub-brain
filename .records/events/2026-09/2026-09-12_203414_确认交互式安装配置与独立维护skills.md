# 确认交互式安装配置与独立维护 skills

## 已确认方向

用户要求开始时提供交互式安装配置，并将配置、升级等维护工作拆成独立 skill，不与主 skill 合并，以避免多功能指令膨胀和后期拆分成本。上一轮“无需新增独立 skill”的建议不再采用；共用底层执行程序的原则不变。

## 本次方案

- 建议首版划分 `magicdub`、`magicdub-setup`、`magicdub-upgrader`；以后增加字幕 skill。具体名称和向导细节为建议，未视为用户逐项确认。
- README 提供简短安装请求入口，由 agent 取得并读取 setup 指令，完成依赖、目录、所需凭据与入口验证；初次安装不能依赖未安装 skill 自动触发。
- setup 可重复执行、仅补缺项并恢复中断；主 skill 只预检和路由，配置补齐后继续原视频任务，不重复配置或重置已有结果。
- 版本检查与升级归 upgrader；Star 复用公共规则，建议在首次安装配置或实际升级成功后判定，不另建 Star skill。
- 只读核对 Codex 官方按需加载与安装文档，以及 social-lurker 已有三个 skill 的职责；不将 Grok Bot 绑定或旧实现参数套用到 MagicDub。

## 当前状态

成果已保存在 Draft，相关安装、升级规划和 CURRENT 已同步。正式 Release 尚待更新，本次未实现代码、安装软件、调用付费 API、执行 Star 或 Git 交付。先前事件保留原样，此决定细化并调整其方案，不撤销升级与 Star 功能需求。
