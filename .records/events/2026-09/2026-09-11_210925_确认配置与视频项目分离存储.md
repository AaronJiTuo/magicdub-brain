# 确认配置与视频项目分离存储

## 用户确认

- 用户认可上一轮目录建议，并要求补充 Windows 与 Linux 的安排。
- 用户级密钥和全局配置与视频项目数据分开存放；每个视频有可见、可指定位置的独立项目目录。
- 中间产物与最终成品保存在同一视频项目中，便于预览、备份和不同 skill 复用。
- 转写、人工修改的译文和时间轴是应保留的项目数据，不作为普通临时缓存自动清理。
- 项目目录允许使用用户自己的工作区或外接存储，与 skill 安装目录分离。

## 确认边界

- 本次记录存放原则的认可；各系统的具体默认路径、配置文件格式和项目文件名尚需收敛，不能将新提出的 Windows / Linux 路径建议当作用户已确认或程序已实现的行为。
- 原 Release 已有独立视频项目的基础原则，尚未补齐跨平台路径解析规则；本次未改写 Release，也未创建实际配置、素材或代码目录。
