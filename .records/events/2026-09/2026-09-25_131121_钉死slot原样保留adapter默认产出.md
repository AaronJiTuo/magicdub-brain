# 钉死 slot 原样保留 adapter 默认产出

## 结论

各 slot（sep／asr／translation／tts）对 adapter 返回物 **只 commit／写 state，不做转码、重采样、改封装或其它内容处理**；正式路径扩展名跟随 adapter。需要特定格式时由使用方（下一 adapter 或 fixed step）自行处理。写入 Releases/06 §3.3 第 8 条。

## 配套

- Adapter 调用外部 API 时用供应商**默认**输出格式（例如 Demucs 不强制 `output_format=wav`）。
- Adapter 契约内自产衍生轨（如 Demucs 本地 `non_speech`）除外。
- 代码仓：Whisper 已去掉上传前 16k 转码；下载按远程扩展名落盘；Demucs 去掉强制 wav。

## 影响

后续不得在 slot 末尾为「给下一步用」预转格式。
