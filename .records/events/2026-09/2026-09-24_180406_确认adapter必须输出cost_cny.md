# 全局约定：每个 adapter 必须输出本次 cost_cny

## 结果

用户确认系统设计：凡 adapter 成功 return 须带本次花费 `cost_cny`（人民币）。计费算法留在 adapter（按供应商定价／用量本地估算）；**不**把 fal billing-events 等账单查询放到 slot／pipeline，以免上移厂商耦合。slot 只消费 `cost_cny` 写 ledger／`assets.cost`。Releases/06 §2.4／§3 已钉死。代码未改。

## 背景与理由

实测 fal 模型结果无费用字段；billing-events 需 Admin Key 且即时查常空，不宜作热路径。故费用由 adapter 自洽估算（如 IndexTTS2：`wave` 时长 ceil 秒 × 单价）。

## 对当前项目的影响

现有 fal adapter 常返回 `cost_cny=None`，与新规范漂移；后续实现按 adapter 补齐估算后再发版。
