# v0.3.0 新版 Steve Jobs 真实译制技术验收完成

## 结果

用户针对已展示的三题回复“按推荐”，本次明确选择英语→简体中文、Whisper、Demucs，固定 IndexTTS 2。用独立候选快照与新项目处理 Steve Jobs 前 90 秒，原项目及日常 v0.2.0 安装未改变。

- 28 句配音、28 条同名 SRT、48 kHz 双声道浮点 WAV 混音母版已交付；成片实际 90.023357 秒。
- 完整音视频解码无错误，成片画面与准备阶段裁剪后的源片逐帧哈希一致，原素材副本 SHA-256 匹配。字幕逐条匹配最终译文显示规则及实际对齐配音时间。
- Demucs 接受 44.1 kHz 双声道 float32 WAV，原始返回为同采样率双声道 PCM16；TTS 接受原生双声道浮点参考，28 份原始结果均为 22.05 kHz 单声道 PCM16。ASR 独立 16 kHz 单声道副本通过；背景逐样本验证 Alpha=1.00 相减。
- 中文回转写覆盖全部 28 句。去标点并统一“18／十八”后，仅“里德”出现同音字“理德”。不据此宣称主观音色验收通过。
