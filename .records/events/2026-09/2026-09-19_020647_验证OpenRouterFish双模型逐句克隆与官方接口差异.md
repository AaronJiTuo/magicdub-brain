# OpenRouter Fish 双模型核心克隆可用，官方 API 不完全等价

## 结果

对 fish-audio/s2.1-pro 与 fish-audio/s2.1-pro-free:free 各发起 15 次真实请求：每个模型 12 次生成成功、3 次预设边界返回 400。六组基础单份 Instant clone 共 12/12 成功，覆盖 0.24／0.28／0.38 秒未补长原声、5.72／5.84／8.06 秒参考及既有中文译文。24 份新输出加 18 份原声、IndexTTS、官方 Fish 对照共 42 份均严格完整解码通过；旧媒体复制与 PCM 封装前后字节保持一致。浏览器 42 份媒体加载无错误，超短筛选显示 3 句。

## 接口边界

单参考克隆、MP3、PCM 和 HTTP 分块传输已验证。第二份参考与直接 WAV 均返回 400；provider options 指定 WAV 仍输出 MP3。64 kbps 码率已生效，24 kHz 请求仍输出 44.1 kHz。顶层 speed=1.5 两条结果缩短；temperature=2 超出官方文档范围仍被接受，不能断言高级参数完整原样透传。情绪标签只证明生成成功；音色、中文口音、标签遵循、多说话人、音色管理、WebSocket 与并发／全长质量尚未验收。

## 费用与成果

Key 累计用量从 0 增至 $0.013785，与 919 UTF-8 付费目标字节乘以公开单价一致；按固定汇率 ×7 为 ¥0.096495。最后一笔在延迟查询后体现，保留前后快照；即时逐笔 generation 查询返回 404，不伪称逐笔账单。测试凭据仅进程内存使用，已清空并关闭服务。

报告及可复用程序见关联 Draft。试听与脱敏原始凭据位于 MagicDub 项目根目录 experiments/openrouter-fish-20260919/；内含 index.html、report.md、summary.json、validation.json、requests 与 baseline。未修改 magicdub-skills 或已有视频项目，未启动全长译制，未提交或推送 Git。后续若接入须单独适配 JSON 参考、PCM 封装和经验证参数，不能只换 base URL。
