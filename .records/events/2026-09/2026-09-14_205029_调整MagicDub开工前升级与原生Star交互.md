# MagicDub 开工前升级及原生可选维护交互

用户要求将版本检查移到开工前，无新版保持静默；发现新版以原生选项收集意愿，选择升级先升级后继续，跳过或忽略直接工作。升级及 Star 均不再以普通问句结束会话等待打字，等待选项期间可暂停当前业务。本轮按此修改代码仓库和正式规划的维护小节。

四个 skill 通过共用 `skills/magicdub/references/maintenance.md` 路由维护交互：下载／译制开工前只检查一次，内部阶段、setup／upgrader 往返不重复检查；无有效新版或自动检查失败无用户提示。选择升级后读取新 ROOT 的技能及引用、核验运行入口并继续原素材；旧项目仍固定旧快照。新增 CLI 参数将升级绑定所选 tag 与完整 SHA，期间出现更高版本不会替换用户选择；目标失效或不匹配不会执行安装。

Star 状态查询改为只读，移除写入永久“已处理邀请”的行为；采用原生行动／跳过选项，写入前核对账号和精确 HTTP 状态，已 Star 不重复写入，写入后要求回读 204。首次完整设置或真实升级成功才具备邀请条件，有待续业务时延后到整项结果交付。缺少认证或检查失败静默跳过。

等待时长为本轮实现默认 60 秒：已向用户询问偏好，尚未收到选择，按已说明的默认值完成。该窗口仅跳过可选动作，不授权升级、Star 或代选必答参数；迟到升级不打断已运行媒体步骤。拒绝同类邀请在本会话内生效，不保存长期偏好。若用户后续选择其他时长，应同步共用规则和说明。

验收：152 项完整回归通过（含版本绑定、目标改变／过期、防降级、Star 只读／账号变化／写后核验）；ruff 与 Git 差异检查通过；44 文件清单完整，隔离本地安装四入口及共用引用可用，新 CLI 参数与开发安装静默跳过通过。没有付费模型或真实 Star 写操作。

当前为本地待发布修改，版本号和远端正式稳定版仍为 0.4.1；未 commit、push、tag、Release，也未升级日常安装。原生选项在真实视频任务中的等待、关闭、超时及升级后继续尚未端到端验收；本轮程序回归和隔离安装不替代该项。Windows／WSL／Linux 体验未实测。
