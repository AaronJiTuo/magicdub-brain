# 确认 CLI 命令名为 magicdub

## 结果

用户确认：运行命令改为 **`magicdub`**；仓库／包名继续 **`magicdub-cli`**；内部标识不变（`engine: "magicdub-cli"`、`program.name`、`~/.magicdub/cli/`、任务目录等）。不做 `magicdub-cli` 过渡 alias。v1.0.0 前可推倒重来，不必兼容已装用户。

## 背景与理由

原命令 `magicdub-cli` 偏长；短名更贴品牌。与 skills 入口名 `magicdub` 不争 PATH。仅自用，无需双入口。

## 证据与成果位置

- 规范：`Releases/06_magicdub-cli系统设计.md` §1／§2.1／M0 已改为 `magicdub`
- 代码仓：`pyproject.toml` scripts、`cli.py` prog、`README.md` 已改为 `magicdub`

## 对当前项目的影响

文档与本地代码以 `magicdub` 为唯一 shell 入口；安装／验收示例用 `magicdub --version` 与 `magicdub run …`。

## 未完成与下一步

代码仓改动尚未 commit／push（需另行授权）。已装旧入口的本机需重装 tool 后才会出现 `magicdub`。
