# 确认 cli 配置／凭据分目录并与 skills 脱钩

## 结果

用户确认：配置与凭据均放在 `~/.magicdub/`；cli 使用子目录 **`cli`**（不用 `magicdub-cli`）。布局为：

- `~/.magicdub/cli/config.yaml`（可选）
- `~/.magicdub/cli/credentials`（cli 专用）

加载顺序：仅读上述 credentials，再加环境变量覆盖；**不再**读 `~/.magicdub/credentials` 或 `credentials.env`。`magicdub-skills` 本轮不改。日后路径规划可再议。

## 背景与理由

配置／凭据与 skills 共用易混淆；子目录 `cli` 在父路径已含 `magicdub` 时避免冗余命名。

## 证据与成果位置

- 规范：`Releases/06` §1／§2.1／§7.1 已更新
- 代码：`credentials_path()` → `cli/credentials`；`load_credentials` 去掉 skills 回落
- 本机：已将所需 key 迁移写入 `~/.magicdub/cli/credentials`（mode 600）；skills 原文件保留未改

## 对当前项目的影响

新跑 cli 只认 `~/.magicdub/cli/`；skills 安装与凭据路径不变。

## 未完成与下一步

代码仓改动待 commit／push；skills 侧分目录若需要另开任务。
