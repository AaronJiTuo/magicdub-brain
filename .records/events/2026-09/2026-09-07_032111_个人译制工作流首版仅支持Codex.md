# MagicDub 个人译制工作流首版仅支持 Codex

## 结果

- 用户明确决定先基于 Codex 开发，首版放弃 DeepSeek Harness 适配，以尽快得到可用版本为优先目标。
- 新工作流主要服务用户自己的视频译制与内容账号运营。首版目标是输入视频文件，输出译制完成的新视频；后续再逐步支持选择阶段模型和修改中间结果。

## 背景与理由

- 用户认为 Web 版灵活性不足、改动慢，CLI 版可视性和操作便利性不足，因此规划通过 Codex 中的 skill 执行主 pipeline。
- 本次收窄适配范围由用户在当前讨论中明确提出，不是 agent 根据可移植性推断的选择。

## 对当前项目的影响

- 新工作流处于规划阶段；后续首版设计与验收以 Codex 为目标，不把 DeepSeek Harness 兼容性列为交付条件。
- 现有 Release 仍描述 Web 产品路线。本决定增加个人使用工作流的规划范围，不代表既有 Web 路线被整体废弃，也未修改 Release。
- 继续遵守永远不做唇形或口型修正的项目边界。

## 未完成与下一步

- 仓库名称、skill/plugin 包装、工作目录布局、审校页形态及其开发时点仍在讨论，尚未形成用户确认的方案。
- 尚未创建新项目仓库、实现或安装译制 skill/plugin，也未验证新的端到端流程。
