# 确认继续 DeepSeek 并形成上下文约束改写计划

## 结果

用户决定继续使用 `deepseek-flash`，按讨论方向改造 CLI，并要求先梳理计划和未决项。保留纯 CLI、无 agent／无微调边界，不将此前 GPT 模型比较作为换模型授权。

已形成计划 Draft：固定每轮全文／当前译稿上下文、最小必要编辑、严格 ID 校验、相同文本复用已有音频、保留尝试与费用，以及离线／真实样片验收。第一版建议沿用三轮总上限与任务冻结时长区间，暂不加入独立语义审校；这些实现建议及字段细节见 Draft，不冒充全部已由用户逐项确认。

## 未决与边界

- 三轮均未达标及原样返回后的最终选稿政策待用户选择：回到首译、保持按时长选择，或另加审校。任何选择都不构成已保证全文连贯。
- 真实问题视频／任务目录尚待定位；它影响质量验收，不阻塞不依赖样片的方案设计。
- 本轮只形成计划和检查点；关联 CLI 工作区干净，代码基线未变。未实施、未请求付费模型、未修改 Release、未执行 Git 交付或升级日常安装。
