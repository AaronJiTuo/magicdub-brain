# 按用户要求将 MVSep 固定区域切换为 DE2

## 决定与实现

用户明确表示账户显示 Server 为 DE2，并要求代码改用 DE2。账户显示来自用户陈述，本轮没有重新查询账号。此前“香港入口有官方依据”的发现仍成立，但当前实现区域按本次明确要求改为 DE2。

关联代码仓库基于本地提交 `062e7ced7be237b257cafaa8e4aea35bfec94877`，修改 `src/magicdub/models.py` 的冻结地址，以及 `src/magicdub/mvsep.py` 的基础地址和下载主机校验：创建、轮询及历史对账统一使用 `https://de2.mvsep.com/api`，下载仅接受 `https://de2.mvsep.com/storage/`。DnR v3 · Mel+SCNet 及全部模型参数保持不变。

同步参数与项目格式文档、现有专项测试和本地 release.json 文件摘要。已有香港区域项目继续使用原来的冻结配置与运行快照；不自动改写项目或跨区域重提任务。历史实测文件继续保留香港地址，以免把旧实验伪写成 DE2 验收。

## 验证与交付边界

- MVSep 专项 31 项通过，覆盖 DE2 创建、同 hash 轮询、历史对账、下载与缓存恢复；新增异区域结果拒绝用例，并确认错误结果不触发重复提交。
- 受控响应配合真实 FFmpeg 验证三轨、背景合成、音频规格与短参考；本次没有新增真实 API 请求或费用，不代表 DE2 远端实测。
- 修改的 Python 文件 Ruff 检查通过，git diff --check 通过。
- 开发环境实际加载的两个修改模块与源码逐字节一致；53 个分发文件摘要校验通过。
- 仅修改本地源码与 brain 记录；未提交、推送、发布或升级日常安装。版本号保持 0.6.0，正式 Release 未改动。
