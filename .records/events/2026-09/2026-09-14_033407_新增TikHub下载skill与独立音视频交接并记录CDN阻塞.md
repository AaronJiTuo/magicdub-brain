# 新增 TikHub 下载 skill 与独立音视频交接

## 结果

用户要求增加 YouTube 高品质下载技能，并明确选择 TikHub API。magicdub-skills 本地 0.3.0 候选新增 skills/magicdub-download、youtube.py 和 assets.py；保持此前 SRT、Alpha=1.00 和高品质音频修改。

- 使用 /api/v1/youtube/web_v2/get_video_streams_v2，一次获取独立流的已签名地址。最高规格限定为接口本次可用结果，按清晰度／帧率／编码和音轨质量排序，不承诺上传原件质量，不静默降低规格。
- 保存 media/ 原始独立文件与 asset.json；主 skill 新增 create --asset，在同一目录原地交接。完整视频直接复用，不复制、不合并再拆分；音频只为后续分离解码。原始音视频均纳入完整性校验。
- TikHub Key 通过用户指定普通输入保存到本机 MagicDub 凭据，下载不强制配置 fal／百炼或译制默认模型。仅下载不问译制三题，真正交接译制时仍独立提交三项选择。
- 解析提交前记账，成功按官方 $0.003 估算，固定人民币汇率；失败／未知尝试不删除，解析缓存避免媒体重试重复付费。原地交接继承同一账本与任务 ID。
- CDN 有界 Range 续传、长度／摘要检查、完整文件复用；最多三次媒体重试，保留失败现场，不自动反复付费解析。请求不会向 CDN 发送 TikHub Key。
- 安装器支持第四入口与历史三入口快照；新增 --register-current，以便旧 v0.2 安装器升级到新快照后补齐入口，保留 previous 和配置。更新 README、参数交接与下载说明。

## 验证

88 项测试、Ruff、四技能结构校验、diff 检查通过。受控 API 配合真实 FFmpeg 验证独立音视频下载和续传、零复制／零合并交接、音频解码、最终画面哈希、SRT、两份原件校验和费用继承。隔离目录真实 uv 安装四入口成功；日常安装仍固定 v0.2.0，未切换。

用户指定样片 ymuWHoWMlNQ：真实 TikHub 解析返回 367 秒，最高 1440p／30 fps；选择 itag 400 AV1 2560×1440 与 itag 251 Opus／48 kHz 原声 en-US。API 的部分重复 itag 大小与签名 URL clen 不一致，保留两者证据并以实际下载／ffprobe 为准。

一次真实解析请求成功，估算 USD 0.003 = CNY 0.021，显示 ¥0.02，未精确对账。CDN 整文件及后续分段请求反复 HTTP 403；更换常规请求头、明确 Range 和有界重试后有部分 206 成功，但未完成全文件。最终保留视频 14,024,704 字节、音频 1,179,648 字节，未生成 ready asset；不宣称真实下载、真实译制交接或听感验收通过。未发起 fal／百炼调用。
