# Qwen Audio 3.0 ASR Flash Filetrans 真实链路通过，双人仍分为三标签

## 结果

用户授权测试指定模型，使用本机已配置的百炼 Key 与北京业务空间专属地址。复用既有 Fun-ASR 的 32 秒、16 kHz 单声道 PCM16 双人英语样片，SHA-256 一致；一次上传和一次 `qwen-audio-3.0-asr-flash-filetrans` 提交成功，任务及文件子任务均 SUCCEEDED。提交至结果解析 5.514 秒，含 5 秒轮询间隔。

返回 7 段、70 个词，句级和词级时间戳有效，7 段都有 speaker_id；但双人仍为 0／1／2 三标签，孤立 “dots.” 与 Fun-ASR 一样被单独标成第三人。末段比 Fun-ASR 多出 “months” 并起始更早，该词真值与归属未人工复核。不能据此认定整体准确率改善或下降。
