# Demucs／SAM 首轮对比与计费口径

用户同意比较 Demucs 与 SAM，并提醒计算秒不能当成音频秒。本轮五次真实请求完成：同一 60 秒高品质原音，Demucs、SAM 时间段 1／3 候选；两组 near-silent 后补测文字基线 FLOAT 及只改变输入编码的 PCM24。原始输入、请求、结果、状态、计费、测量及试听均完整保存。

Demucs 有效削弱讲话参考区约 36.98 dB，同时观众反应候选短窗降低约 16.45 dB。三组 FLOAT SAM 的 target 在讲话参考区比原音低约 49～50 dB，未完成有效分离；PCM24 后提取信号恢复，但相减背景讲话区只降低约 4.36 dB，当前不能直接替换 Demucs。格式兼容性是有对照依据的待证假说，不是确定唯一根因；具体事件类别与听感待用户确认。

更正上一轮笼统计费描述：Whisper 的实时单位为 compute seconds（USD 0.0008），现有程序已用 inference_time；本轮 Demucs 是 60 音频秒，推理仅 5.224 秒；SAM 1／3 候选是 2／4 单位而非实际推理秒。此前 Demucs／SAM 时长估算被 billable header 支持，不能泛化到其他模型。

全部 API 成功、无付费重试，包含效果不合格结果的费用估算合计 ¥3.794000。依据实时单价和供应商返回计费量；billing-events 403，尚未确认扣款。本轮没有新翻译、TTS 或 QA。

已交付 35 组 WAV／FLAC 试听、同时间切换页面及独立局部原音保留示范；全部媒体完整解码通过，播放跳转及普通暂停控件已验证。示范时间窗不是自动检测能力。未改业务代码、默认模型、安装或执行 Git 交付。后续优先试听并验证 PCM24 差异可重复性，暂不采用 ElevenLabs。
