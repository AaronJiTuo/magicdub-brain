# 用户提供的 AnyTLS 节点出口定位为圣何塞

用户询问一条 AnyTLS 美国节点是否为洛杉矶。使用官方 sing-box v1.14.0 macOS arm64 临时程序，下载后核对 GitHub Release 提供的 SHA-256；仅创建 loopback HTTP 监听，不启用系统代理或 TUN，不修改 Quantumult X。

实际通过指定节点访问 IPwho.is 获得出口 IP；随后用默认线路向 IPinfo 查询同一出口 IP。两家均返回美国加利福尼亚州 San Jose（圣何塞），运营商 Eons Data Communications Limited。America/Los_Angeles 是时区标识，不能用来证明城市是洛杉矶。结论仅限当前出口及数据库识别，未证明物理机房位置，也未证明供应商没有动态出口。

默认线路在测试前后均返回同一纽约出口，确认本次程序专用代理未改变默认出口。临时进程已停止，配置凭据、程序和日志已删除；未把节点密码、主机或整条分享信息写入项目资料，未持久配置 MAGICDUB_MEDIA_PROXY。没有发起 TikHub、分离、ASR 或 TTS 请求，没有重跑下载，没有改代码／Git／日常安装。

仅本机忽略证据：magicdub-skills 的 acceptance-local/node-geolocation.json，保存去凭据的定位结果与清理状态。当前仍缺已验证的洛杉矶出口，原 YouTube 完整下载及真实交接尚未通过。此节点不应被标记为洛杉矶；需另一条节点或供应商进一步确认。
