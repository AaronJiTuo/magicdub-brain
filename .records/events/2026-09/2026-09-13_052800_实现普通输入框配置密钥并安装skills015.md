# 实现普通输入框配置密钥并安装 skills 0.1.5

## 结果

- 用户明确决定使用普通输入框粘贴 API Key。setup 现在对缺少或需更换的 Key 调用原生异步问答工具，仅传标题、不传选项；提交后自动保存并继续。已有凭据允许复用，指定文件导入仍可用。
- 新增 save-credentials --stdin 接口，接收 JSON，校验变量名和非空单行值，仅替换本次提交项，保留其他凭据。临时文件写入后原子替换，文件权限为 0600；凭据加载关闭变量插值。程序只输出状态、变量名、位置与环境覆盖提示。
- 普通输入进入对话及工具调用，不宣称密码遮罩或不留记录；不回显值，不把值写入 brain、项目媒体数据或 Git。此前“不在普通框输入”的实现约束已按用户新决定更改。
- 0.1.5 已提交推送并从 GitHub 安装到本机，三个当前快照 skill 均实际发现并启用。

## 验证与边界

- 23 项测试及 Ruff 通过，包含 CLI 输入、替换与保留、特殊字符、无效输入不覆盖及环境优先提示；setup skill 结构、manifest 和差异检查通过。
- 用隔离临时目录和合成测试值验证安装版 launcher 的标准输入保存入口成功，没有替换用户真实密钥，没有付费模型调用。
- 实际用户在输入框中提交并继续完整配置的 UI 流程仍待验证。当前完成的是工具调用指令与保存程序；未增加本地密码窗口。
