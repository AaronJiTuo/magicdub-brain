# Demucs 固定类别、SAM 时间段能力与笑声保留研究

已查 fal 文档／OpenAPI、htdemucs_ft 官方说明及源码、SAM 官方 README／源码／论文，并核对当前 skills 实现。Demucs stems 为固定枚举，不能传 speech 或 talk；shifts／overlap 不改变声音类别。SAM 支持自由描述，官方建议简短的小写短语；可比较 speech 与 man speaking，不宣称换词一定保留笑声。

fal 另有 span-separate 接口，支持提示词和正负时间段、完整时长输出；纯笑声而无目标讲话的区域可作负示例，讲话与笑声重叠区不能按“无讲话”排除。fal 两个接口候选数上限均为 7，不能照搬上游 README 的 8。SAM 原生预处理混成单声道，target／residual 为联合生成；实际 fal 声道与两路背景保真度仍待实测。

当前代码全时长减去分离人声，SAM residual 未参与后续处理。建议优先验证“确认无讲话时保留原音，讲话重叠区用语义／时间段分离”，将参考人声与待替换讲话分开定义，并比较模型 residual 与原音减 target。方案及短片段 A/B 验收规则已保存在关联 Draft；它们是研究建议，未成为新默认或正式规划。

用户听到的具体笑声丢失尚未定位验证。本轮无模型调用或新增费用，无代码／配置／成片修改，无 Git 交付；不把文档能力或源码分析写成已修复效果。每个视频独立选择模型、原素材保全和现有版本边界不变。
