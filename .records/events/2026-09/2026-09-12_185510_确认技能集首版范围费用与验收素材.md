# 确认技能集首版范围、费用统计、MIT 与验收素材

## 用户确认

- 首版必须包含多人对话、声音克隆、背景音乐保留；首版不要求字幕，但字幕需在近期后续版本交付。不限定短视频，范围包括约两小时电影。
- 接受 Skill 引导、Codex 交互、自带程序执行 API 与媒体处理的分工；部分环节需要提供多个模型选项供使用者选择，不静默切换模型。
- 接受跨 skill 共享项目数据基础、复制原视频、保留成功结果、限制自动重试与保留已有导出。
- 确定 Python 3.12+、FFmpeg / ffprobe、uv；magicdub-skills 采用 MIT 许可证，公开时间仍未定。
- 每一步记录费用，每个任务结束输出总费用；USD / CNY 分列，包含失败步骤实际花费。
- 指定 `Drafts/test_by_step/source/stevejobs.mp4`、`Drafts/test_by_step/source/trump_full.mp4` 验收；异步问答确认方向为英语 → 简体中文。

## 成果与核验

- 上述决定及建议的项目格式、逐次尝试费用账本、长视频与恢复设计保存在关联 Draft；字段名、目录名、费用核对细节等具体建议未视为用户逐项确认或已实现。
- 本地核验两段文件可读取，时长分别为 885.191111 秒和 1790.072744 秒；媒体参数与 SHA-256 已保存。未调用付费模型、未生成译制视频，不能据此宣称多人或两小时电影能力验收通过。
- 只读核对 fal 官方计费文档发现按请求费用接口需要 Admin API key；建议单独配置对账权限，缺乏实账时标注估算 / 待核实。尚未验证实际账号接口。
