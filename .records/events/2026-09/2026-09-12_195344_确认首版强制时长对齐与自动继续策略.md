# 确认首版强制时长对齐、自动继续和不设预算

## 用户确认

- 首批在当前 macOS 环境完成完整验收；代码保持跨平台，Windows、WSL、Linux 分别验证后再声明支持。
- 译文忠实原意、自然口语，可为时长调整措辞，保留关键事实、数字与人物关系；优先调整译文和停顿。
- 首版效果处理不好时自动继续，不暂停让用户决定。
- 当译制质量与对齐无法兼顾时，强制把配音拉伸或压缩到原句同等长度；轻微变速不作为阻止继续的限制。
- 首版不关心任务预算，不设置预算输入、金额上限或超预算暂停。已有有限重试、费用逐步记录与结束汇总要求继续有效。

## 方案落地边界

- 上述决定与建议的逐句时间伸缩、质量标记和采样长度校验已补入 Draft；并非程序已实现或媒体已经验收。
- 有可用音频的质量问题自动完成并记录提示；完全缺乏可用产物的 API / 文件 / 合成故障仍需如实记录失败与费用，不制造成功、不增加人工审校环节或静默更换模型。
- 旧 Release 和上一轮建议中的质量暂停、轻微变速边界、预算待定等表述需在后续正式规划中同步；历史 Record 保留，不回写。
