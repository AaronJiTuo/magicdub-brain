# 百炼上传成功，但 Fun-ASR 真实识别被模型权限拒绝

## 结果

用户授权寻找已有音频并执行一轮上传与 Fun-ASR 可用性验证。选择已有双人交替英语演讲样片的人声：32 秒、16 kHz、单声道 PCM16 WAV；完整解码通过，源文件未改变。

百炼上传凭证与文件上传均返回 HTTP 200；文件绑定 fun-asr，上传耗时约 0.242 秒。随后复用 MagicDub v0.5.1 正式 ASR 实现，在隔离项目使用 oss:// 地址及资源解析请求头。Fun-ASR 提交返回 HTTP 403 / Model.AccessDenied / Model access denied.，没有 task_id 或 usage，未进入识别与结果下载阶段。共 1 次 ASR 提交，未重提，也未调用 fal。

当前 Key 的实际模型访问仍受阻；上传可用不等于识别可用。官方说明该错误码是模型访问授权不足，具体是否来自子业务空间缺少模型授权尚未通过控制台验证。旧北京兼容域名仍受当前官方 HTTP 文档支持，未把改域名当作已证实修复方案。

## 证据与影响

验证脚本、脱敏摘要、参数与官方资料见关联 Draft。原始响应保存在程序目录内被 Git 忽略的 private/；不保存或输出 API Key、上传临时签名。识别费用记录为 pending，无账单证据，不宣称零扣费。

不修改正式代码、日常凭据、默认模型或原媒体项目，不提交或推送。此结果补足此前只读核查的实时权限证据。下一步为核实当前 Key 所属地域、业务空间及 fun-asr 模型调用授权，再进行新的明确测试轮次。已有拒绝响应继续保留。
