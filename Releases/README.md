## 放什么

## 原则

- 这里的内容默认 **「可照着做」**，不写不确定的猜想。
- 草稿成熟到「读者不用追问也能照做」时，才从 `Drafts/` 移入这里。
- 内容被替代或过时后，移入 `Archive/`，并在新文档中写明替代 / 迁移关系。

## 命名建议

可用 `NN_主题.md` 的编号前缀让核心文档保持固定顺序，例如 `00_项目总览.md`、`01_技术框架.md`、`02_术语表.md` 等。具体文档因项目而异，按需创建即可。
