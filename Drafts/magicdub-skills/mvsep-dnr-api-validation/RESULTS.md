账号本来允许花费 Credits，但余额为零；成功请求和免费次数变化证明本轮可用免费队列。不能因此把免费次数称为赠送 Credits，或推断付费并发、长片稳定性和更高规格已通过验证。仅一次请求，不构成 SLA／压测。

## 对照素材和客观观察

试听提供原音、已有 Demucs 背景、MVSep Music+SFX、三条原始分离轨，以及复用同一份中文配音的两组混音。所有试听统一增益 1.0，无逐轨归一化、变速或局部原音补回；网页 WAV 为统一 48 kHz 双声道 PCM16，另保留 FLAC；原始三轨不改写。

| 窗口 | Demucs 背景相对原声 RMS | MVSep Music+SFX 相对原声 RMS |
| --- | ---: | ---: |
| 8.2–12.6 秒讲话参考 | -36.98 dB | -27.66 dB |
| 16–31 秒笑话与观众反应 | -33.49 dB | -23.29 dB |
| 26.8–28.2 秒观众反应候选 | -16.45 dB | -0.63 dB |

观众反应候选窗中 MVSep 留下更多能量，主要落在 SFX；这为试听提供线索，不能直接宣称笑声完整或分离更好。讲话窗口内背景能量也更高，可能包含环境声、混响或讲话残留，尚未通过主观试听区分。样本没有独立纯净真值，因此不计算或宣称 SDR 提升。

20 份媒体（原音、三轨原始 WAV、8 份试听 WAV、8 份 FLAC）均通过 `ffmpeg -v error -xerror` 完整解码，时长均为 60 秒。试听音轨峰值均未超过 1，无需统一衰减。
