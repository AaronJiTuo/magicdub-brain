# Demucs 与 SAM 现场声保留：首轮实测

日期：2026-09-14。用户试听结论：**本轮只有 Demucs 达到可用成品标准，整体效果最好；所有已测 SAM 配置（包括 PCM24 补测）均未达到可用标准，只能作为实验草稿。** Demucs 丢失部分笑声仍是待改进项。此结论限定于本次素材、参数与交付结果。

## 输入与变量

采用既有高品质 Steve Jobs 验收项目的前 60 秒，44.1 kHz 双声道 FLOAT WAV；逐样本验证与原项目对应前缀完全一致。Demucs 使用 htdemucs_ft、vocals、shifts=1、overlap=0.25、WAV。为消除 90 秒历史缓存与 60 秒新请求上下文不同的影响，Demucs 也重新请求一次。

SAM 时间段两组使用同一输入、man speaking、quality、正示例 8.2–12.6 秒及 38.0–40.8 秒、trim_to_span=false、WAV，仅 reranking_candidates 为 1 或 3。正例定位依据既有讲话转写，没有将 ASR 空白擅自标为负时间段。观众反应及讲话重叠的具体区间尚未取得人工听感标注，因此本轮不声称完整覆盖已标注的三种声学场景。

两组出现近乎空的 target 后，追加 speech／balanced／predict_spans=false 的文字基线。其浮点输入仍异常，因此最后增加同参数、同音量与声道、仅输入编码改为 PCM24 的一组。PCM24 与 FLOAT 的最大样本差为 1.19e-7、RMS 差为 6.81e-8；没有降采样、降成单声道或另行归一化。SAM 每个配置只运行一次，没有固定随机种子，不能将一次差异等同已证实唯一根因。

## 结果

| 方案 | 讲话参考区 target 相对原音 | 相减背景的讲话参考区衰减 | 初步判定 |
| --- | ---: | ---: | --- |
| Demucs | +0.003 dB | 36.98 dB | 讲话提取有效，但观众反应候选短窗也被削弱 |
| SAM 时间段 1 候选，FLOAT | −49.69 dB | 约 0 dB | 未通过有效讲话提取检查 |
| SAM 时间段 3 候选，FLOAT | −49.46 dB | 约 0 dB | 未通过有效讲话提取检查；加候选未解决 |
| SAM 文字基线，FLOAT | −49.96 dB | 约 0 dB | 同样近乎空提取 |
| SAM 文字基线，PCM24 | −6.44 dB | 4.36 dB | 提取信号显著恢复，但背景仍高度接近原讲话，不能直接替换 |

讲话参考区为 8.2–12.6 秒，Demucs 在 26.8–28.2 秒的观众反应候选短窗使 RMS 下降 16.45 dB；这支持“此处理会同时削弱停顿区域声音”的判断。该窗口的准确事件类别、听感与原用户指出的笑声是否同一处，仍须试听确认，不能用单纯响度证明笑声完整性。

SAM PCM24 组的模型 residual 在讲话参考区下降约 5.90 dB，而相减背景约 4.36 dB；尚无可据以宣称英文完全去除的结果。FLOAT／PCM24 对照提示音频编码兼容性或预处理路径值得排查，但仍需控制随机性复测或供应商证据；不把暂定原因写成确定模型缺陷。

原生返回：Demucs 为 44.1 kHz 双声道 PCM16；SAM 各组 target 与 residual 均为 48 kHz 单声道 PCM16。源文件左右相关系数 0.999985，接近重复声道，因此本轮不能验证宽立体声现场的保真程度。

## 试听交付与验证

`runs/stevejobs-first60/review/index.html` 为对比页。可切换原音、提取人声、相减背景、SAM residual、复用旧中文配音的混音。所有版本共用同一增益 1.0，没有分别放大弱结果；35 路 FLOAT WAV 与 35 路 24 位 FLAC 播放副本均完整解码通过，无非有限数，均为 60 秒。返回模型原始文件也保留。没有新翻译、TTS 或 QA 费用。

额外提供 26.8–28.2 秒放回原音的混音示范，边缘 40 ms 平滑交叉；平顶区域逐样本等于原音。它只是固定时间窗的示范，不是自动无讲话检测，也不属于 SAM 提取能力。边界、尾声和英文残留仍须听感审查，不能先上线为默认。

本地预览仅服务 review 子目录；支持字节范围请求，播放、跳转、切换及暂停已验证。内置浏览器原生音频暂停控件曾引发预览页崩溃，已改用普通网页控件并验证暂停与页面保留。模型结果不受该浏览器问题影响。

## 计费口径与本次费用

本轮直接读取 fal Pricing API，并记录每个结果的 x-fal-billable-units 与 status.metrics.inference_time。音频时长、计算秒与等待墙钟时间严格分开。

| 请求 | 输入音频 | 推理耗时 | 供应商返回计费量 | 人民币估算 |
| --- | ---: | ---: | --- | ---: |
| Demucs | 60 秒 | 5.224 秒 | seconds × 60，USD 0.0007／单位 | ¥0.294000 |
| SAM 时间段 1 候选 | 60 秒 | 31.043 秒 | units × 2，USD 0.05／单位 | ¥0.700000 |
| SAM 时间段 3 候选 | 60 秒 | 33.190 秒 | units × 4，USD 0.05／单位 | ¥1.400000 |
| SAM 文字 FLOAT | 60 秒 | 33.027 秒 | units × 2，USD 0.05／单位 | ¥0.700000 |
| SAM 文字 PCM24 | 60 秒 | 35.297 秒 | units × 2，USD 0.05／单位 | ¥0.700000 |
| **合计** | | | | **¥3.794000** |

五次请求全部 API 成功，没有自动付费重试；包括效果不合格试验的全部费用。金额依据供应商返回计费量 × 实时单价 × 固定汇率 7，billing-events 返回 403、当前未配置账单权限 Key，故标注 estimated，不冒充确认扣款。

同轮 Pricing API 对 Whisper 明确返回 `compute seconds`、USD 0.0008；本次没有调用 Whisper。历史 90 秒样片 Whisper 的推理量为 4.4299998 秒，现有 MagicDub 费用程序采用该值估算；Demucs 则推理约 13.513 秒、计费 header 为 90。不能用音频时长计算 Whisper，也不能用 Demucs 的 5.224 秒推理量计算本轮分离账单。上一轮分离价格表对 Demucs／SAM 的音频时长估算被本次返回量支持；但“这些模型都不是 compute seconds”的笼统描述应更正。

现有代码已区别 compute seconds 与音频 seconds；另发现 SAM 费用在缺失计费 header 的回退路径仅覆盖文本单候选，尚未泛化到时间段与候选附加费。本轮验证脚本按 endpoint、输出时长和候选数显式处理，并优先使用返回计费量；未据此修改业务代码。

来源：[fal Pricing](https://fal.ai/docs/platform-apis/v1/models/pricing)、[Billing Events](https://fal.ai/docs/platform-apis/v1/models/billing-events)、[SAM 标价](https://fal.ai/models/fal-ai/sam-audio/span-separate)。原始请求、状态、结果、费用与测量均在 runs/ 中，可按 request_id 对账；该目录已忽略，不提交媒体或临时 URL。

## 用户试听验收（2026-09-14）

用户实际试听后明确反馈：Demucs 虽然把笑声分到了讲话一侧，但整体效果最好，最终只有 Demucs 能听；其余结果最多只能算草稿。本轮 SAM 各组因此判为未通过主观听感验收，PCM24 的客观提取改善也不足以使其成为可用替代。

本次反馈确认整体可用性，不补写具体笑声时间点，也不视为对固定窗口恢复示范、自动检测能力或其他素材的独立验收。前述解码通过、接口成功和信号测量保留为技术证据，不代替主观验收。

## 后续方向

继续以 Demucs 为当前可用基线。后续改进应以保住其整体听感为前提，再研究局部恢复观众笑声与现场声；无讲话区的边界及讲话与笑声重叠仍需验证。SAM 本轮结果保留为实验资料，格式差异仍只是待证线索，暂无可用于替换 Demucs 的方案。

此次仅记录用户验收，没有追加模型调用、费用或业务代码改动；后续方案尚未实施。暂不采用 ElevenLabs。
